# Statistics Roadmap
We use this document to keep a list of what statistics we plan to track and categorize them.
We also add information related to display of these statistics.

## Dream
This sections contains information about what stats we want to track for dreams.

### Global
We want to track the following stats for all dreams globally.

The user will be able to set the time range manually, although the default will be all-time.

**Chronological Distribution:** Diagram with time on the x-axis that displays a histogram of when how many dreams were dreamt.

We use a bar-chart and choose the bin size dynamically based on how wide the time range of the user is.
We add a running average if we have enough data points.

**Day-of-week Distribution:** Diagram that displays how frequent which day-of-the-week is.

We use a bar-chart and display the most common one.

**Dream frequency:** Average count of dreams per week.

We use big display letters to show the number.

**Dream streak** The current and biggest number of consecutive dreams.

We use big display letters to show the numbers.

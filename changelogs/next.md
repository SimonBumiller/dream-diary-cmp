# Changelog `1.2.0`  &rarr;  `TODO`

Note: Changes in *italic* are changes not visible to users.

## Bug fixes
- Fixed a bug where alphabetic-based sorting would put lowercase items at the end, despite being of higher alphabetic rank
- Fixed a bug where legacy-backups were expected to have non-null `notes` field for relations
- *Changed the navigation api-structures of the feature:* modules*

## Minor Changes
- Added German translation
- Made statistics range persisted
- Person-chips are now the color of the first tag applied to the person, if existing
- *The `:feature:home` module was split into several other `feature:*` modules*

## New Features
- Added per-dream clearness and intensity values
- Tags can now only be applied to either dreams or persons. This can be specified on a tag-basis when creating one
- Added dream sort options for clearness and intensity
